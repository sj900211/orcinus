M1 · 다중선택 아카이브 다운로드

🤖여러 원격 항목을 하나의 .tar.gz로 — 구현·적대적 리뷰·커밋90602c9056
원격 파일/폴더를 다중 선택(Ctrl/Shift)해 **단일 `.tar.gz`**로 내려받는 기능을 구현. - 백엔드 `streamTarToFile`을 `remotePaths[]`로 확장: 공통 조상 디렉토리를 `-C`로, 나머지를 상대 멤버로. 중첩·중복 경로 제거. - 선택 훅 `useFileExplorerSelection`을 Server Explorer에 연결(Ctrl/Shift 다중선택), 행 메뉴에 "Download N items as archive…". - **적대적 리뷰 → 확정 3건 교정**: HIGH tar 옵션-인젝션(대시 파일명 → `--` 종결자), MED 시그널 종료를 성공 오인, LOW 중복 경로. - 게이트(타입체크·린트·테스트 9/9) 통과 후 커밋.

🤖프리뷰 = 더블클릭/메뉴로 전환 + 진행순서(A→11-2→11-3) 제안c290518417
병렬 정찰(프리뷰 배선 + DnD 범위)로 근거 확보 후: - **단일 클릭 = 선택만**, 더블클릭/우클릭 "Preview" = 열람으로 변경. 파일명 텍스트 더블클릭이 rename 훅에 가로채이던 함정도, SFTP엔 rename이 없어 그 경로를 프리뷰로 재사용해 해결. - **진행 순서 제안**: 공통 MIME 선결(A) → 업로드(11-2, 저위험) → 다운로드(11-3, 고위험). 로컬 탐색기 드롭 경로를 건드리는 11-3을 마지막으로 격리.

M3 · 업로드 드롭 (11-2)

🤖공통 MIME + 로컬→원격 업로드 드롭 — 구현·리뷰·커밋3862ac947f
- **Step A**: 원격 행에만 `SFTP_FILE_DRAG_MIME`(`{hostId,paths}`) 태깅 → 드롭 지점이 로컬/원격 출처 구분. - **11-2**: 다이얼로그 없는 `sftp:uploadPaths`(파일→`uploadFilesInto`, 디렉토리→`uploadDirectoriesInto`). 공유 행 훅에 opt-in `onExternalPathsDrop` 추가(로컬 무손상). 원격 행·배경 드롭 분기. - **적대적 3렌즈 리뷰 → 확정 3건**: HIGH 최상위 심링크 디렉토리 업로드가 링크 대상(예: `~/.ssh`) 유출 → `lstat`로 거부. MED 배경 다중드롭 1건 잘림 → 다중 경로 MIME. MED 렌더러 신뢰 모델(기존 `performUpload`와 동일) → 보고.
🧑"모두 성공적으로 검증되었어" + 분할 패널·네이티브 에디터 요청
업로드 드롭 승인. 두 수정 요청: 1. "Show SFTP" 시 SFTP 패널이 로컬 패널을 **가려 스크롤이 안 생김** → 진짜 분할로. 2. SFTP 프리뷰가 별도 Monaco 팝업인데, **로컬 파일과 같은 Orca 에디터로, 메인 워크스페이스에** 열리게.

MED unified 탭이 별도 영속돼 하이드레이션 고아 → SFTP 탭 영속 제외.

🤖서버 아이콘으로 탭 구분 + 원격 마크다운 프리뷰 수정4082c399ae · 82d5306ba8

M6 · 다운로드 드롭 (11-3)

🤖원격→로컬 다운로드 드롭 — 구현·리뷰·커밋fc3157dd4b
- Plan 에이전트로 로컬 드롭 경로(git 이동·undo 무손상) + 원격 디렉토리 다운로드 방식 설계. - 다이얼로그 없는 `sftp:downloadToDir`: 파일=temp+rename, **디렉토리=재귀 walk**(readdir+fastGet, tar 의존성 없음). 11-2의 `onExternalPathsDrop` 훅을 로컬 행에 재사용 + 배경 드롭 분기. hostId=드래그 페이로드. **`connectionId==null`(진짜 로컬 워크트리) 게이트**(SSH 백엔드 거부). - **적대적 3렌즈 리뷰 → 확정 2건**: HIGH 기존 로컬 파일 무경고 덮어쓰기 → `deconflictName`("name copy") 비파괴. MED 심링크가 선택적 mode 비트 의존 → `classifyRemoteEntry`로 S_IFREG/S_IFDIR 확정 분류, 그 외 스킵.
🧑"모두 문제 없이 테스트 완료했어. 승인할께"
11-3 승인. 던전 11(Split+DnD) 전 조각 완료.

M7 · upstream 재동기화 (시도 → 연기)

🤖201커밋 병합 시도 — 텍스트·기계적·게이트 해결, 창별 딜리버리가 벽
`upstream/main`(201커밋 뒤)을 `main`에 병합: - 텍스트 충돌 14개 병렬 에이전트로 해결(정체성 보존), **기계적 5건** 확정 적용, **pty 게이트 재직조**(arg 15건) 완료 → 관련 테스트 15개 통과, 타입체크 0. 게이트 실패 근본원인 = 병합이 라우터 주입 누락 → 복원. - **확정된 유일 블로커**: `pty-project-window-stream-routing`(7건) = 멀티윈도우 PTY 스트림 전달 서브시스템(약 1,500줄)을 upstream 분할 위에 **재구현**하는 feature-scale 작업. 반쪽 이식은 단일창 전달 오염 → 전용 던전 필요.
🧑"병합 중단·유예" 선택
경계가 확정된 만큼 유예 결정. `git reset --hard origin/main`로 원복(`feat/sftp` 무손상), 정제된 진단을 메모리·월드맵에 기록(다음 담당자가 바로 이어받도록).
