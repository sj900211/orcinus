# 컨셉 — Orcinus

> 이 파일이 **활성 컨셉**이다. 진행 방식(`collab-protocol`·`guided-steps`)은 이 파일을 읽어 "무엇을·왜·어떤 테마로"를 파악한다.
> 생성: `INIT.md` 초기화 인터뷰 수행 결과 (2026-08-19)

## 1. 도메인·목표

- **도메인**: Electron 데스크톱 앱 개발 — 대규모 오픈소스(TypeScript/React) fork 커스터마이징
- **최종 목표**: 3개 로드맵(① Fork & 리브랜딩 빌드 ② Workspace New Window ③ SFTP Server Explorer)이 완성·설치되어 **Orcinus를 일상 개발 도구로 사용하게 되면 끝**
- **authoritative spec**: `REQUIREMENT.md` (환경 상세: `COMPOSITION.md`)

## 2. 사용자 컨텍스트

- **전문성 수준**: **입문자** — 이 도메인(Electron·React 프론트엔드) 기준. 단계를 잘게 쪼개고 새 용어를 풀어 설명한다.
- **경험 유무**: Electron·React는 처음. 백엔드 개발 경험자 — 개발 일반 지식(Git·터미널·서버 등)은 있으므로 기본기 설명은 불필요.
- **선호·주의사항**: 한국어 소통. 처음 나오는 기술 용어에는 짧은 풀이를 붙인다.

## 3. 테마 (선택)

- **테마**: 게임 퀘스트 — task 완료 시 보상이 열리는 구조로 흥미 유지
- **진행 단위 이름**: 원정(마일스톤) → 던전(스토리) → 퀘스트(task) → 하위 퀘스트. 난이도 표기 ★모험가 / ★★베테랑 / ★★★영웅
- **마일스톤 전환 리셋 톤**: 게임 세계관 서사 — 길드 홀 귀환 · 회복 물약(휴식) · 전리품 확인(성과) · 다음 포탈(예고)
- **추적 항목 별칭**: 🕳️ 히든 퀘스트(빼먹은 것) / 💀 놓쳐버린 적(의도와 다르게 된 것) / 🕊️ 자비를 베푼 적(미룬 것)

## 4. 진행 단위 구조

- **마일스톤(원정)**: `REQUIREMENT.md`의 로드맵 3개 = 원정 3개. 각 원정의 첫 던전은 **정찰**(가능성 검토 · 코드 구조 파악 · 더 나은 방향 검토 — 요구사항 원문의 명시 요구)
  1. **원정 1 — Fork & 리브랜딩** (★ 모험가): fork → 개발환경 구축 → 빌드 성공 → 아이콘·이름 변경 → 설치 테스트
  2. **원정 2 — New Window** (★★ 베테랑): Workspace를 새 창(New Window)으로 띄우기
  3. **원정 3 — SFTP 원양 탐사** (★★★ 영웅): SSH 탭 + Server Explorer + 업로드·다운로드
  - 순서는 1 → 2 → 3. 원정 2·3의 순서는 정찰 결과에 따라 조정 가능
- **작업 단위**: 던전(기능 덩어리) → 퀘스트(1회 작업 — `guided-steps`의 1분 단위 단계로 안내) → 하위 퀘스트
- **진행 추적 문서**: `docs/진행/01-월드맵.md` — 단일 진실 공급원, 원정·던전 현황을 한눈에
- **세부 로드맵**: `docs/진행/미니맵/원정N-이름.md` — 원정별 던전·퀘스트 상세

## 5. 확정된 결정·제약

- 환경 상세는 `COMPOSITION.md` 참조. 핵심 결정 요약:
  - upstream 스택 그대로: Electron + TypeScript/React + Vite + **pnpm**
  - Git + 개인 GitHub fork(공개) · `main` 기본 브랜치 + `upstream` 주기 병합 · 원정별 feature 브랜치(`feat/rebrand`·`feat/new-window`·`feat/sftp`)
  - 지원 OS: Windows·macOS·Linux (로컬은 Windows 빌드, 나머지는 GitHub Actions)
  - 무료 운영 (GitHub 무료 + 로컬 빌드)
- **MIT 라이선스 고지 유지** — 리브랜딩해도 원본 LICENSE·저작권 고지 보존
- **upstream 병합 리듬 유지** — 원본이 매일 릴리스할 정도로 활발. 원정 사이마다 동기화 권장
- 3개 원정은 **각각 독립 진행**, 원정마다 정찰(검토) 선행

## 6. 산출물·품질 기준

- **주요 산출물**: ① 리브랜딩된 Orcinus 설치 파일(Windows 우선, macOS·Linux 포함) ② Workspace New Window 기능 ③ SFTP Server Explorer 기능 + 원정별 정찰 보고서 + 개인 GitHub fork 저장소
- **품질 게이트**: 원정별 체크리스트(클리어 조건) + **제작자 직접 사용 판정**. "던전 클리어" 선언은 언제나 제작자의 몫 (→ `collab-protocol` 판정 게이트)
- **기준 문서**: `docs/진행/길드-규약.md` — 검수에서 발견된 지적·판정 기준을 판례처럼 축적
